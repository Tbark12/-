## 🚀 كيفية التشغيل

### الطريقة الأسهل (Windows)
1. انقر مرتين على ملف `open-website.bat`
2. سيفتح الموقع تلقائياً في متصفحك

### الطريقة اليدوية
1. افتح ملف `index.html` مباشرة في أي متصفح حديث

### باستخدام سيرفر محلي (اختياري)
```bash
# Python
python -m http.server 8000

# Node.js
npx serve

# PHP
php -S localhost:8000
```

## 🍽️ تعديل القائمة

### تعديل الأطباق
1. افتح `index.html`
2. ابحث عن أقسام `food` و `desserts`
3. عدل:
   - اسم الطبق (`food-name`, `dessert-name`)
   - الوصف (`food-description`, `dessert-description`)
   - السعر (`food-price`, `dessert-price`)
   - الصور (استبدل روابط Unsplash)

### إضافة طبق جديد
```html
<div class="food-card">
    <div class="food-image">
        <img src="رابط_الصورة" alt="اسم_الطبق" class="food-img">
        <div class="food-overlay">
            <button class="btn btn-order-card" onclick="orderDish('اسم_الطبق', السعر)">اطلب الآن</button>
        </div>
    </div>
    <div class="food-info">
        <h3 class="food-name">اسم الطبق</h3>
        <p class="food-description">وصف الطبق</p>
        <div class="food-footer">
            <span class="food-price">السعر ₪</span>
            <button class="btn btn-small" onclick="orderDish('اسم_الطبق', السعر)">اطلب الآن</button>
        </div>
    </div>
</div>
```

## 🎨 العناصر الزخرفية الفلسطينية

- تظهر في قسم القصة
- أنيميشن خفيف للتأثير الطبيعي
